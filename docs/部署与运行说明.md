# 部署与运行

本地推荐 Python 3.12 + uv。运行 `uv sync --extra dev`、`uv run alembic upgrade head`、`uv run cyberrisk-intel seed-demo`、`uv run streamlit run app.py`。数据库默认位于 `data/cyberrisk.db`，可通过 `CYBERRISK_DATABASE_URL` 覆盖。`init-db` 只用于无需迁移历史的一次性本地试用，不应与 Alembic 初始化混用。

本地试用可由 CLI 自动建表；正式维护数据库版本时执行 `uv run alembic upgrade head`。初始迁移包含关系表、审计表与 SQLite FTS5 虚拟表。

生产化前需迁移到 PostgreSQL、设置只读/写入权限边界、增加备份、运行迁移、锁定出站白名单并保护 LLM 密钥。当前版本是个人研究平台，不是多租户生产服务。
