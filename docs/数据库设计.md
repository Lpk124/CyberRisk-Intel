# 数据库与数据字典

主要实体：`policy`、`security_event`、`vulnerability`、`attack_technique`、`risk_theme`、`industry`、`threat_pattern`、`control`。`entity_relation` 保存跨实体方向、谓词、证据片段、来源、置信度、创建方式和复核状态。

来源与审计包括 `source`、`raw_document`、`ingestion_run`、`extraction_candidate` 和 `review_record`。政策通过 `document_type` 区分法律、行政法规、部门规章、规范性文件、国家标准和技术框架，并支持 `policy_version → policy_clause → policy_obligation`。事件多来源通过 `event_source` 保存。

`security_event.incident_date` 可空，避免把报告日期冒充事件日期；`incident_end_date` 保存官方明确给出的时间范围。`discovered_date` 与 `disclosed_date` 分别表示发现和披露/提交日期。适配器不能从缺失字段推断根因、CVE 或 ATT&CK Technique。

结构化列表在 SQLite 中以 JSON 文本保存；未知值保持 `NULL` 或明确的 `unknown`，不得与空列表、零值或不适用混合。稳定外部标识（CVE、ATT&CK、控制编号）设置唯一约束；内部标识统一为 UUID。
