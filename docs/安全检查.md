# 安全检查

本检查覆盖 Python、Streamlit、SQLite/FTS、外部 HTTP 抓取、文件导出和可选 LLM 接口。

## 已落实

- 内部实体使用 UUID；SQL 和 FTS 查询均参数化，检索词先做受限分词。
- KEV、ATT&CK 和 CVE 在线入口固定为官方 URL；CVE ID 先验证再拼接路径。
- HTTP 下载限制协议、超时和最大体积，不记录 LLM 密钥。
- LLM 凭据仅从环境变量读取，模型引用必须属于检索上下文，否则拒绝发布。
- Streamlit 不启用不安全 HTML；报告 HTML 对所有动态文本进行转义。
- 抓取内容不执行，正式关系只能在复核后进入检索、关系图和报告。

## 部署前仍需完成

- 当前是单用户本地研究工具，没有身份认证、租户隔离或生产级权限模型。
- 若允许用户自定义抓取 URL，必须增加 DNS/IP 解析后的 SSRF 防护和出站白名单。
- 若迁移 PostgreSQL 或暴露 API，应增加最小权限账号、TLS 终止、速率限制、审计日志和备份恢复演练。
- 每次发布执行依赖漏洞审计，并人工确认误报、可利用性与升级影响。
