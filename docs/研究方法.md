# 研究方法

本项目采用描述性研究，不从公开样本推断真实事件发生率或因果关系。分析快照必须记录生成时间、筛选条件、样本数和代码版本。

数据质量检查至少覆盖来源、复核、时间、行业、根因和关系证据。比较时间窗口时同时报告来源覆盖变化；缺失月份不自动连接；绝对数量和比例应同时展示。

政策主题以人工词表为主。政策主题图按发布年份展示主题记录占比，同时保留记录数与当年样本量；同一文件可贡献多个主题，因此该比例不是文件占比。TF-IDF/NMF 只能用于探索性候选，必须人工命名。事件到 CVE/ATT&CK 的正式边只能来自明确来源证据。每张研究图可下载聚合数据，并采用零基线、可读标签及颜色以外的冗余表达。
