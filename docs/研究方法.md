# 研究方法

本项目采用描述性研究，不从公开样本推断真实事件发生率或因果关系。分析快照必须记录生成时间、筛选条件、样本数和代码版本。

数据质量检查至少覆盖来源、复核、时间、行业、根因和关系证据。比较时间窗口时同时报告来源覆盖变化；缺失月份不自动连接；绝对数量和比例应同时展示。

事件语料采用单批分来源上限：HHS OCR、California DOJ 和 Massachusetts OCABR 首批各 25 条，Washington AGO 首批 13 条。HHS 稳定 ID 迁移复验时官方列表新增 3 条，当前本地快照因此为 103 条。该配额用于降低单一监管辖区和医疗行业对建设快照的支配，不代表分层随机抽样。自动采集记录统一为 `pending_review`；只有已复核记录可进入正式事实结论。

事件发生日期与披露日期严格区分。官方汇总只给出提交/披露日期时，`incident_date` 保持 `NULL`，趋势分析可显式使用披露日期替代并标注 `date_basis`。报告机构、受影响机构和实际发生泄露的机构可能不同，不根据通知主体自动推断责任主体。跨州重复通知只产生消歧候选，未经人工核验不自动合并。

政策主题以人工词表为主。政策主题图按发布年份展示主题记录占比，同时保留记录数与当年样本量；同一文件可贡献多个主题，因此该比例不是文件占比。TF-IDF/NMF 只能用于探索性候选，必须人工命名。事件到 CVE/ATT&CK 的正式边只能来自明确来源证据。每张研究图可下载聚合数据，并采用零基线、可读标签及颜色以外的冗余表达。
