# 系统架构

```text
官方源/导入文件
  → ingestion（KEV、CVE、ATT&CK、政策/事件）
  → domain + db（SQLite/SQLAlchemy、来源、版本、复核）
  → retrieval（FTS5/BM25 + 可选 Embedding + RRF）
  → analytics/services（趋势、关系、报告、RAG）
  → Streamlit UI
```

业务逻辑均位于 `src/cyberrisk_intel`，Streamlit 只调用服务层。未来可以替换为 PostgreSQL 或封装 API，无需修改领域含义。V1 不引入微服务、队列、图数据库和多 Agent。

关系图由已发布的 `entity_relation` 临时构建，限制两跳和 100 个节点，不是知识图谱事实推理系统。
